# pdf-converter
PDF Converter Tool

Convert, merge, and compress your files into optimized PDF documents.

Supported File Formats
PDF: .pdf
Microsoft Word: .docx
Microsoft PowerPoint: .pptx
Microsoft Excel: .xlsx, .xls, .xlsb
OpenDocument Spreadsheet: .ods
Data Files: .csv, .tsv
Markdown: .md
Text Files: .txt
Structured Data: .json, .xml
Log Files: .log
Images: .png, .jpg, .webp, .svg
Key Features
Convert to PDF — Convert supported file formats into PDF.
Merge Files — Combine multiple files and different file types into a single PDF document.
Compress PDF — Reduce PDF file size while maintaining the best possible document quality.
Organize Files — Arrange and manage files before creating the final PDF.
Optimize PDF Size — Create smaller PDF files that are easier to store, share, and upload.
